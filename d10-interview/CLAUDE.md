# AI 면접 코치 — 프로젝트 규칙 (d10-interview/CLAUDE.md 에 붙이기)

> 이 파일을 `git-practice/d10-interview/CLAUDE.md` 로 붙여 넣고 Claude Code를 새로 시작해요.
> 맨 아래 "실수에서 배운 규칙"에 오늘 찾은 AI 실수를 한 줄씩 더해요.

## 무엇을 만드나
- 클래스로(가상 회사) 신입 **모의면접 서비스**. Streamlit 화면 + OpenAI API
- 흐름: 시작(직군 · 회사 · 내 경험) → 면접 5문제(꼬리 질문 포함) → 위원 4명 평가 → 고친 답 → 재도전 비교 → 리포트

## 파일 나누기 (이 구조를 지켜)
| 파일 | 하는 일 | 하지 않는 일 |
| --- | --- | --- |
| `prompts.py` | 프롬프트 문자열과 JSON 스키마만 | 함수 · API 호출 |
| `llm.py` | OpenAI 호출 **한 곳**. `ask_json(instructions, user_input, schema, name)` | 화면 코드 |
| `coach.py` | 질문 고르기 · 점수 합계 · 비교 · 리포트 (AI 없이 계산) | API 호출 |
| `app.py` | Streamlit 화면만 | 프롬프트 문자열 · API 직접 호출 |
| `data/questions.csv` | 질문 은행 (칸: 직군, 유형, 질문, 보는 점) | |

## 프롬프트 규칙
- **프롬프트는 내가 쓴다.** Claude Code는 `prompts.py`의 문장을 바꾸지 말고, 바꾸고 싶으면 제안만 해
- AI 출력은 모두 **JSON 스키마(strict)** 로 받는다. 글로 받아서 잘라 쓰지 않는다
- 상황 블록(회사 · 직군 · 내 경험)은 `CONTEXT` 하나로 만들어 모든 프롬프트에 넣는다
- 지원자가 쓰지 않은 경험 · 숫자 · 회사 정보는 지어내지 않는다. 필요하면 `[확인 필요: ○○]`

## AI는 판단, 코드는 계산
- 질문 개수(5)와 순서, **꼬리 질문 최대 1개**는 코드가 정한다. AI가 더 묻자고 해도 코드가 막는다
- 점수 **합계 · 평균 · 전후 차이는 코드가** 계산한다. AI가 쓴 합계는 쓰지 않는다
- 점수는 범위 밖이면 잘라 쓴다 (기준 0~5, 위원 0~10)
- 고친 답은 기준 점수 미만인 답만 보여 준다

## 화면 규칙
- 면접은 `st.chat_message` + `st.chat_input`, 대화 기록은 `st.session_state`
- 사이드바 **상태창**: 질문 n/5 · 면접관이 본 이해도 · 처음부터 다시
- 에러는 화면에 한국어 한 줄 (`st.error`). 키 · 요청 내용은 화면과 터미널에 찍지 않는다
- 버튼을 `disabled` 로 막지 말고, 누른 뒤 빈칸이면 안내 문장

## 보안
- 키는 `.env` 의 `OPENAI_API_KEY` 하나. `.env` 는 `.gitignore`, `.env.example` 은 이름만
- 배포는 Streamlit Secrets. 브라우저 코드(HTML · JS)에 키 금지
- 기본 모델은 `gpt-6-luna` (`.env` 의 `OPENAI_MODEL`). 비싼 모델로 바꾸려면 먼저 말해

## 끝나면 스스로 점검 (표로 알려 줘)
| 점검 | 확인 방법 |
| --- | --- |
| OpenAI 호출이 `llm.py` 한 곳인가 | `Ctrl+Shift+F` 로 `OpenAI(` 검색 |
| 프롬프트가 `prompts.py` 에만 있나 | `app.py` 에 긴 문자열 없음 |
| 꼬리 질문 최대 1개를 코드가 지키나 | 짧게 답해도 질문당 꼬리 질문 1개까지 |
| 점수 합계를 코드가 다시 계산하나 | `coach.py` 함수 |
| `.env` 가 `git status` 에 안 보이나 | |
